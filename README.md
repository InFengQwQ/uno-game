# UNO Game

## Requirements
- [uv](https://docs.astral.sh/uv/)
- Python 3.12

## Setup

```
uv sync
```

## Run

```
uv run main.py
```

## Build

```
build-nuitka.bat
build-pyinstaller.bat
```
